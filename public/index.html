LABBoard

Проєкт LAB Богдана Завидовського · версія 2.4

Легка дошка для уроків, репетиторства й навчання. Працює без інтернету — усе зберігається на цьому пристрої автоматично.

Як встановити: у Chrome / Edge — «Меню → Встановити LABBoard»; на iPhone / iPad — Safari → «Поділитися» → «На початковий екран».

Жести: один палець / стилус — писати; два пальці — рухати й масштабувати дошку. Якщо пишете стилусом, дотики долонею ігноруються.
