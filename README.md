# LABBoard — дошка, на якій хочеться пояснювати

Інтерактивна дошка для вчителів і учнів. Працює в браузері на будь-якому пристрої, без інтернету й без реєстрації. Проєкт **LAB** Богдана Завидовського.

Цей репозиторій — **ваша власна копія LABBoard разом із сервером спільного уроку**. Розгорніть її один раз у своєму безкоштовному акаунті Cloudflare — і учні писатимуть на вашій дошці зі своїх телефонів, планшетів і ноутбуків.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/bzavydovskyi-spec/labboard)

## Що ви отримаєте

- Дошку за адресою на кшталт `https://labboard.ваше-імʼя.workers.dev` — відкривається на будь-якому пристрої, встановлюється як застосунок.
- Сервер спільного уроку на тій самій адресі: код уроку, QR, «Слідкуйте за мною», пісочниці, «пише лише вчитель», підсумок вправ.
- Учням не потрібні ні акаунти, ні застосунки — лише посилання або код.

> Спільний урок — частина **Функціоналу+**: щоб почати урок на своєму сервері, вставте в LABBoard свій ключ (Меню → «Функціонал+»). Сама дошка на вашій адресі працює й без ключа — у безкоштовному режимі.

## Як розгорнути (близько 10 хвилин, один раз)

1. Створіть безкоштовні акаунти на [github.com](https://github.com/signup) і [cloudflare.com](https://dash.cloudflare.com/sign-up).
2. Натисніть кнопку **Deploy to Cloudflare** вище.
3. Увійдіть у Cloudflare, підключіть GitHub і натисніть **Create and deploy**. Назву можна лишити `labboard`.
4. За хвилину-дві Cloudflare покаже адресу `…workers.dev`. Відкрийте її — це ваша LABBoard. Встановіть її на пристрій: меню браузера → «Встановити».

Детальна інструкція з поясненнями — у файлі [ІНСТРУКЦІЯ.md](ІНСТРУКЦІЯ.md) і в PDF-посібнику LABBoard.

## Безкоштовно і Функціонал+

Базова дошка безкоштовна. **Функціонал+** (199 грн, назавжди, без підписок) відкриває таймер, тести, PDF як фон, кадри-слайди, шторку, бібліотеку уроків, спільний урок і ще багато іншого. Ключ — у боті [@zavydovsky_lab_bot](https://t.me/zavydovsky_lab_bot); вставте його в LABBoard → Меню → «Функціонал+».

## Для розробника

```bash
npm install
npm run dev      # локально: http://127.0.0.1:8787
npm run deploy   # розгорнути у свій акаунт Cloudflare
```

- `public/` — сама дошка (один HTML-файл, працює й офлайн), PDF-модуль, іконки.
- `src/worker.js` — сервер: роздає дошку, `/health`, `/ws?room=КОД` (одна кімната = один Durable Object).
- Сервер не зберігає вміст дошки: учитель — джерело правди, сервер лише пересилає повідомлення.
